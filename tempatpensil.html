Tempat Pensil & HP dari Keyboard Bekas

  1. Alat dan Bahan
    • Alat
      1. Cutter (1 buah)
      2. Penggaris (1 buah)
    • Bahan
      1. Keyboard bekas rusak (1 buah)
      2. PCB keyboard (1 buah)
      3. Lem tembak (5 buah)
  2. Langkah kerja
    1. Bongkar keyboard, pisahkan tombol dan PCB.
    2. Potong PCB menjadi sekat-sekat.
    3. Lem PCB menjadi kotak bersekat untuk pensil.
    4. Tempel tombol-tombol di pinggir sebagai hiasan.
    5. Sisakan celah untuk dudukan HP.
  3. Estimasi biaya
        Alat:
      1. Cutter (1 buah) : Rp15.000
      2. Penggaris (1 buah) : Rp4.000
        Bahan:
      1. Keyboard bekas rusak (1 buah) : Rp30.000
      2. PCB keyboard (1 buah) : Rp40.000
      3. Lem tembak (5 buah) : Rp10.000
  4. Total biaya : Rp99.000
  5. Harga jual : Rp125.000
