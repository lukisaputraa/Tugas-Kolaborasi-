Lampu Tidur Estetik dari Casing CPU Bekas

  1. Alat dan Bahan
    • Alat
      1. Kabel + colokan (1 buah)
    • Bahan
      1. Casing CPU bekas (1 buah)
      2. Lampu LED strip bekas (1 buah)
      3. Cat semprot (1 buah)
  2. Langkah kerja
    1. Kosongkan casing CPU, bersihkan bagian dalam.
    2. Pasang LED strip di dalam casing.
    3. Buat lubang untuk jalur keluar kabel.
    4. Cat ulang casing agar rapi dan tidak karatan.
    5. Uji nyala lampu dan pasang penutupnya.
  3. Estimasi biaya
        Alat:
      1. Kabel + colokan (1 buah) : Rp50.000
        Bahan:
      1. Casing CPU bekas (1 buah) : Rp30.000
      2. Lampu LED strip bekas (1 buah) : Rp15.000
      3. Cat semprot (1 buah) : Rp25.000
  4. Total biaya : Rp120.000
  5. Harga jual : Rp150.000
  6. Laba : Harga jual - Total biaya = Rp30.000
